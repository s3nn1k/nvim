> macOS only. Установка через `./init.sh`.

# Установка

Клонировать репозиторий в `~/.config/nvim`, запустить `./init.sh`. После — открыть Neovim, плагины установятся автоматически.

Обновление зависимостей и плагинов — тот же `./init.sh`, затем `:Lazy update` внутри Neovim.

---

# Зависимости

1. Утилиты:

- gcc
- make
- ripgrep
- git
- Nerd Font

2. Языки:

- golang
- python
- lua
- node / npm

3. LSP:

- lua-language-server
- gopls
- kulala-ls
- pyright
- typescript-language-server

4. Форматтеры:

- prettier
- stylua
- goimports
- taplo
- sql-formatter
- black
